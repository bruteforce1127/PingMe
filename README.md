# PingMe

**PingMe** is a smart personal assistant Android application designed to enhance your daily life and overall wellbeing. It harnesses intelligent reminders, personalized suggestions, mental health support, and content verification features to keep you organized, informed, and balanced.

## Features

### 📅 Smart Reminders & Calendar
- **Date Management:** Set important dates with priority levels.
- **Notifications:** Receive timely notifications through in-app alerts and email.
- **Intelligent Priority Management:** Manage and organize reminders effectively.
- **Calendar Sync:** Synchronize with major calendar platforms.

### 🎁 Personalized Recommendations
- **Gift Suggestions:** Receive tailored gift ideas for every occasion.
- **Work Tools:** Get work-related tips and resource suggestions.
- **Location-Based Offers:** Find points of interest and local recommendations.
- **Productivity Boosters:** Enhance your productivity with customized advice.

### 📍 Location Intelligence
- **Discover & Explore:** Find popular attractions, dining options, and hidden gems nearby.
- **Proactive Notifications:** Get real-time updates about nearby opportunities.
- **Travel Recommendations:** Enjoy personalized suggestions for your next adventure.
- **Navigation:** Integrated transit and navigation features.

### 🤖 AI Assistant Integration
- **Local AI Model:** Powered by the DeepSeek R1 model running directly on your device.
- **Intuitive Interaction:** Natural language processing for human-like conversation.
- **Privacy Focused:** Sensitive data is processed on-device to ensure maximum privacy.
- **Customizable Personality:** Tailor the AI assistant’s personality to your preferences.

## Technology Stack

### Frontend
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Architecture:** MVVM (Model-View-ViewModel)
- **Key Libraries:**
  - Retrofit for API communication
  - Room for local data persistence
  - Coroutines for asynchronous operations
  - Hilt for dependency injection

### Backend
- **Language:** Java
- **Framework:** Spring Boot / Spring 
- **Architecture:** MVC (Model-View-Controller)
- **Advanced Features:**
  - Aspect-Oriented Programming (AOP) for cross-cutting concerns
  - RESTful API design
  - JWT authentication

### Database
- **Database Engine:** PostgreSQL for robust and scalable data storage

### AI Integration
- **Local Intelligence:** DeepSeek R1 model for on-device AI processing
- **Online Intelligence:** Gemini Api

### 🔮 Future Scope

### 🧠 Mental Health & Wellbeing

- **Educational Content:** Read and watch expert-curated mental health articles and videos.
